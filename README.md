Technologies Used
Python – Main programming language
Streamlit – Web application interface
Groq API – Text processing and summarization
Speech-to-Text – Converts meeting audio into text
Python-Dotenv– Manages environment variables and API keys
Git & GitHub – Version control and project hosting

 Features
- Upload meeting audio files
- Convert audio into text
- Generate concise meeting summaries
- Extract important points from meetings
- Simple and user-friendly Streamlit interface
- Secure API key management using environment variables

 How to Run

1. Clone the repository.
2. Create a virtual environment.
3. Activate the virtual environment.
4. Install the required dependencies using `requirements.txt`.
5. Create a `.env` file and add your Groq API key.
6. Run the Streamlit application using `streamlit run app.py`.
7. Upload a meeting audio file and view the transcription and generated summary.
